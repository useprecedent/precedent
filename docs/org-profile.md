# Precedent

Compile the effective instruction set for a repository path. Report always-on conflicts with citations.

This organization publishes [useprecedent/precedent](https://github.com/useprecedent/precedent) and [@useprecedent/precedent](https://www.npmjs.com/package/@useprecedent/precedent) (Apache-2.0).

**What it is.** A file inventory, a documented precedence merge, and a Markdown report. CLI, GitHub Action, and editor skill. Session-only rules are named as out of a git report.

**What it is not.** A guarantee that a model complied. A token compressor. A hosted org dashboard (not in this repository).

| Interface | Install |
| --- | --- |
| CLI | `npx @useprecedent/precedent` |
| GitHub Action | `uses: useprecedent/precedent@v1.4` |
| Skill | `npx skills add useprecedent/precedent` |
